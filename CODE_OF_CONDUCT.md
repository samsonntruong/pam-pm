# Code of Conduct

Be kind and respectful. Assume good intent, welcome newcomers, and keep discussion focused on the work.

## Expected

- Use welcoming language and respect different viewpoints.
- Give constructive feedback tied to the code or docs.
- Help strangers reach a working install; setup friction is a bug.

## Unacceptable

Harassment, insults, unwanted advances, and publishing private information. No exceptions.

## Enforcement

Reports go to the project owner (see LICENSE for the author). Reports are kept confidential. Violations may lead to a warning, temporary ban, or permanent ban from the project spaces.

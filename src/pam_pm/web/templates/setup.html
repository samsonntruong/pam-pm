Step 2: Microsoft Teams (optional)

  1. Step 1: Save keys. Paste the App ID, client secret and Tenant ID above then choose Save. Continue when the fields are saved.
  2. Step 2: Add permissions. In Entra ID add Chat.Read.All and ChannelMessage.Read.All as application permissions then choose Grant admin consent. Without consent polling returns nothing.
  3. Step 3: Download package. Choose Download app package to get the zip built from your saved App ID. Sideload the zip in Teams.
  4. Step 4: Use one tenant. Use the same Entra tenant for the app registration and the Teams client. Tokens do not cross tenants.
  5. Step 5: Name the test chat or channel. Open Pam in Teams and note the 1:1 chat or channel to watch. Use this name when configuring watched chats.
  6. Step 6: Test. Choose Test above and confirm it passes. When green, polling can read the watched chats.

Step 3: Jira

Only needed when Jira is chosen above. Paste the values below, choose Save, then Test.

Where do I find this?
  1. Open id.atlassian.com/manage-profile/security/api-tokens while logged in.
  2. Choose Create API token, name it Pam, then copy the token shown once.
  3. Copy your site URL from the browser address bar when Jira is open. It looks like https://your-site.atlassian.net.
  4. Copy the project key from any issue in that project. It is the letters before the dash, such as PROJ in PROJ-123.

Shapes, not real values: site like https://acme.atlassian.net, email like you@example.com, key like PROJ, token like ATATT... (long).

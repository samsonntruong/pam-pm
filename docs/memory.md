# Team memory

Pam remembers your team so each sprint plan starts from what it already knows.

## What Pam remembers

- People: names, roles, skills, weekly capacity, and timezones.
- Lifecycle: how past estimates compared to actuals, weekly throughput, repeat blockers, and your planning rhythm note.

## Where it is captured

- Kickoff: the roster you provide when starting a project from a brief.
- Interviews: details teammates share in morning check-ins, such as role, skills, and hours per week.

Each entry notes where it came from, and later updates only fill in new information. Nothing is silently overwritten.

## How the forecast uses it

Next-sprint proposals use memory to:

- Fill in capacity for teammates whose roster entry has none.
- Match backlog items to people with the right skills.
- Correct estimates using your past estimation bias.
- Hold work that fits nowhere instead of over planning.

With no memory saved, planning works exactly as before.

## Edit and clear in Settings

Open Settings, then Team memory, to review every teammate, edit roles, skills, and capacity, save the planning rhythm note, remove one person, or clear all of team memory.
